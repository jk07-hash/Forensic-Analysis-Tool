# 🔍 Forensic Analysis Tool

A simple Python-based Digital Forensics tool for analyzing files and generating forensic reports.

## 🚀 Features

- File selection using GUI
- File name and size detection
- File path identification
- Created and modified date/time
- MD5 hash generation
- SHA-1 hash generation
- SHA-256 hash generation
- TXT report generation
- PDF forensic report generation
- Clear/reset option

## 🛠️ Technologies Used

- Python
- Tkinter
- hashlib
- ReportLab
- VS Code
